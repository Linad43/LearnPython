# Функциональность

Проект содержит несколько модулей.

## generators.py

Генераторы для работы с транзакциями.

### filter_by_currency

Фильтрует транзакции по валюте.

```python
filter_by_currency(transactions, "USD")
```

### transaction_descriptions

Возвращает генератор описаний транзакций.

```python
transaction_descriptions(transactions)
```

### card_number_generator

Генерирует номера банковских карт в формате:

```python
0000 0000 0000 0001
0000 0000 0000 0002
```

Пример:

```python
card_number_generator(1, 5)
```

## processing.py

Функции обработки списка транзакций.

```python
filter_by_state
```

Фильтрует транзакции по состоянию.

По умолчанию:

```
EXECUTED
```

Пример:

```python
filter_by_state(transactions, "EXECUTED")
```

### sort_by_date

Сортирует транзакции по дате.

```python
sort_by_date(transactions)
```

По умолчанию сортировка идет от новых к старым.

## decorators.py

Файл функций декораторов

### log

Декоратор логирования

```python
@log(filename)
```

По умолчанию параметр `filename` отсутствует, и тогда логирование идет прямо в консоль. При вводе имени файла, логирование будет в файл.


## Тестирование

В проекте используются тесты pytest.

```

```

```
Python 3.10+
```
